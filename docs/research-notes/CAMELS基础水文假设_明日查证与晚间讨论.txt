基于 CAMELS 公开数据寻找简单水文假设
白天查证清单与晚上发散讨论提纲

整理日期：2026年11月12日
计划查证：2026年11月13日白天

一、当前选题边界

现有资料主要来自 CAMELS 等公开数据集：逐日降雨、温度等气象，出口流量，以及流域属性。研究应先从这些资料能够支持的出口响应规律出发。

核心问题：降雨到出口流量之间，哪些简单假设成立，在哪些状态下失效，怎样把它们写进可检验的模型？

下面都是候选研究假设。基础规律多有研究先例，具体方案是否有新颖性尚未完成文献查证。

二、优先讨论的最小问题

同一流域中，前期湿润程度不同，降雨—径流响应是否可以仅靠幅度变化解释？还是响应形状也必须变化？

可以先写成：
假设 A：r_e(k) = A_e × u(k)
假设 B：r_e(k) = A_e × u(k | w_e)

e 是事件，k 是滞后天数，A_e 控制响应量级，u 是归一化响应形状，w_e 是事件前状态的代理指标。

A 允许响应量变化，但保持形状固定；B 允许形状也随状态变化。若采用响应核，需说明非负性、因果性、归一化及单位；跨事件重叠时需采用一致的组合方式。

可能检验：归一化后，峰现滞后、响应重心、尾部比例和衰减是否仍随前期状态系统变化？B 是否比 A 更好地预测未见事件？

解释边界：从总流量中截取的一段曲线不是实测单位线。它包含前期蓄水释放、事件重叠等影响，需要统一的事件识别和背景流量处理，并做敏感性分析。

三、另外三个简单假设

1. 无雨退水是否服从固定比例

最简单形式：Q(t+1) = a × Q(t)，0 < a < 1。
竞争假设：a 随当前流量水平或季节变化。

先提取连续少雨或无雨且流量下降的片段，画 Q(t+1)/Q(t) 与 Q(t) 的关系。排除或单独分析融雪、零流量、缺测、测量噪声等情况；比较雨量阈值、雨后等待天数和片段长度的影响。

目标：确定固定退水规律何时足够，何时需要状态相关规律。无雨不等于所有补给都停止，退水参数也不能直接等同于真实含水层参数。

2. 前期湿润程度影响幅度还是时间分布

可用前期降雨指数作代理：
API(t) = sum[j=1...L] rho^(j-1) × P(t-j)，0 < rho < 1。

API 只使用事件发生前的降雨，不包含事件本身或未来降雨。它不是实测土壤含水量，也没有自动考虑蒸散和融雪。

先比较降雨总量、持续时间、季节相近的干湿组事件，再判断响应是否不同。API 窗口与衰减系数应在训练/验证阶段确定。

3. 一个记忆时间尺度是否足够

候选形式：
u(k) = omega × u_fast(k) + (1-omega) × u_slow(k)。

比较单尺度、双尺度，以及固定或状态相关的混合权重。重点看退水段、低流和事件尾部，而不只看总 NSE。

两分支首先称为“快、慢时间尺度”。缺少额外证据时，不把它们直接认定为地表径流和地下径流。注意检查参数是否稳定、两分支是否退化成相同形状。

四、明天白天查资料时记录什么

每篇相关论文记录以下内容：
1. 它提出的水文假设是什么？
2. 使用什么数据，什么时间尺度？
3. 是从观测统计检验规律，还是只用模型扰动解释规律？
4. 怎样识别事件、处理基流背景、事件重叠、积雪和季节？
5. 是否区分响应幅度和归一化形状？
6. 是否已研究前期状态控制响应核或退水规律？
7. 对照模型是什么，性能提升能否支持其机制解释？
8. 有没有公开代码、数据和可复现的处理规则？
9. 与我们的具体问题相比，真正尚未解决的部分是什么？

五、明天可以先做的低成本检查

先选少量资料完整、降雨主导的流域，核查所选气象驱动版本、时间连续性和单位。

先画降雨与流量过程线，检查能否识别足够多的较独立事件；再画若干连续无雨退水段。若事件重叠严重，可考虑连续时间响应估计，不强行切成独立事件。

优先用训练期观察规律。验证期确定筛选和模型规则；最终检验保留独立数据。若已查看原测试期形成假设，后续需明确这属于探索，并另作确认性评价。

可记录一个小表：流域编号、事件日期、雨量、持续时间、事件前 API、初始流量、峰现滞后、响应重心、尾部比例、事件是否重叠。响应量如何扣除背景必须写清楚。

比较事件组时，要控制雨量、持续时间和季节差异；跨流域分析时不能把同一事件内每日样本当成完全独立的重复。可以按事件或水文年组织不确定性检验。

CAMELS 的部分水文签名由较长时期流量计算而来；若用作训练输入或先验，需核查计算时期，防止间接使用验证/测试期信息。

六、需要保留的解释边界

日数据支持天尺度响应差异，不足以识别小时级传播和雨强阈值机制。
响应核随前期状态变化，是待检验的结构假设，不自动证明真实内部产流机制。
较高 NSE 不等于过程正确；NSE 也不是“准确率百分比”。
不能要求当天流量一定小于当天降雨，流量可能来自前期蓄水。
由原始降雨估计的响应不自动满足经典单位线对有效降雨和直接径流的定义。
比例响应与两场降雨响应的可加性是不同命题。
一个简单假设是否值得研究，取决于其适用条件、失效方式和证据，而不只看它是否复杂。

九、目前掌握的国内资料条件

用户已转换出淮河上游大坡岭水文站资料，提供的控制面积为 1640 km²，可用雨量站约 7—8 个，空间分布较均匀。研究目标时段为 2006—2024 年；实际完整率、雨站有效时期、日界、流量统计口径和转换质量尚需逐文件核验。

用户还可能收集其他大型流域最上游山区的站点，例如黑河鹰落峡。第一轮建议只在大坡岭开展，其他流域用于后续扩展。鹰落峡等寒区流域需另行处理降雪、融雪等过程，不能直接套用降雨主导流域的事件规则。

选择无大型水库、人类影响较小的流域，有助于解释自然响应，但仍需核查研究时期内小型拦蓄、引取水、灌溉、站点变化和显著土地覆盖变化。文献历史描述不自动代表整个 2006—2024 年。

以下是拟开展的验证方案，并非已经得到的研究结果。

十、六类发散问题在这组资料下的适用程度

1. 地表类型与水文功能分区：有条件可做。用土地覆盖、地形和植被作分区背景，检验分区是否提高事件响应解释能力；不能直接把遥感分类标定为超渗区或蓄满区。
2. 前期状态与响应变化：优先考虑。区分湿润影响响应量与影响响应形状；内部产流机制切换仍需更多证据。
3. 动态水文连通性：适合作为探索。可以研究地形连接代理与湿润状态的共同作用，不能仅凭出口流量确定真实地下流路。
4. 降雨空间位置与响应：多站资料下值得优先考虑。先检验站网是否确实观测到足够不同的空间降雨配置。
5. 人类设施改变流路：在当前自然流域选择目标下优先级较低，先作为混杂因素核查。
6. 内部过程补偿与可辨识性：作为辅助验证。检查流量表现相近的模型是否具有不同内部解释，以及遥感能排除哪些解释。

优先组合：前期状态 + 降雨空间配置，以内部状态可信度作为辅助；不同时铺开六条路线。

十一、先写出可被否定的假设

H0：在降雨过程和季节等条件相近时，前期干湿主要改变响应量，归一化响应形状近似稳定。
H1：控制降雨过程和季节后，前期干湿仍改变响应的时间分布。
H2：进一步考虑前期状态后，降雨空间位置仍能解释额外响应差异。

首轮以 H0 与 H1 为主，H2 为扩展。不能预设“湿润一定更快”。已有研究在两个资料丰富的流域观察到湿润主要增强响应幅度、峰现时间却未明显改变。

验证分三层：
第一层：分析工具是否能正确识别已知差异；
第二层：观测资料中是否存在稳健的条件关联；
第三层：允许该变化的模型结构是否有独立预测价值。

这三层不能自动升级为真实产流机制的因果证明。

十二、第一步  整理统一日表和站网

逐日主表至少包含：日期、日流量、每个雨站的日降雨、面平均降雨、可用气象、缺测与质量标记。

空间资料至少包含：站点坐标、站点有效时期、流域边界、出口位置。计算流路距离时还需要 DEM 和河网信息。

优先检查：
1. 雨量和流量的观测日界是否一致。不能为提高相关性而任意平移日期。
2. 日流量是否为日平均值，转换过程是否保留缺测符号、日期和小数精度。抽取若干原始记录人工核对。
3. 雨站是否迁移、缺测或更换，站网变化是否造成面雨量与空间指标的虚假变化。
4. 预处理、标准化、阈值和筛选参数只利用开发期资料确定。

单位换算：
若 Q 为日平均流量，单位 m³/s，A 为面积，单位 km²，则日径流深：
q(mm/day) = 86.4 × Q / A。
大坡岭暂按 A=1640，最终以核实后的控制面积为准。

可参考的时间划分：
2006—2016 年：探索规律、拟合；
2017—2020 年：确定分析规则和模型参数；
2021—2024 年：最终保留检验。
这只是候选划分，需根据实际资料完整性确定；开发期可做按年份分块交叉验证。

十三、第二步  用合成资料自检分析方法

使用真实降雨序列生成两种已知答案的合成流量：
A 情形：前期湿润只改变响应幅度，响应核形状固定；
B 情形：前期湿润同时改变响应形状。

叠加合理背景和噪声，使用与真实资料完全相同的事件提取、背景处理、归一化和检验流程。

检查是否把 A 误判成“形状变化”，以及能否发现 B 中设定的差异。还可逐渐减小形状差异或增加噪声，了解当前日尺度流程的识别能力。

此步骤只验证分析方法，不能证明自然流域机制。

十四、第三步  建事件表并人工检查

先人工核查 10—20 场用于流程检查。这不是正式统计样本量要求。

事件优先依据降雨定义，雨日阈值、事件合并间隔和响应窗口在训练期确定。不能只挑涨峰明显、回落漂亮的事件。先分析较孤立的事件，但结论需说明适用于该子样本。

若事件大量重叠、独立样本不足，应转向连续时序集合响应分析，而不是强行切分。

每场事件建议记录：
事件编号、流域编号、开始日期、结束日期、水文年；
事件总雨量、降雨天数、最大日雨量占比、降雨时间重心；
事件前 API、事件前流量 Q0；
上中下游降雨配置、降雨加权流路距离；
背景调整响应体积、峰值增量；
响应重心、日峰滞后、预先定义的前段或尾段响应份额；
缺测、事件重叠、弱响应、背景处理等标记。

前期湿润主代理：
API(t) = sum[j=1...L] rho^(j-1) × Pbar(t-j)。
只用事件发生前的面降雨，不包含本次事件或未来降雨。API 是湿润代理，不是真实土壤含水量。Q0 可作替代代理及敏感性分析；不要未经思考同时将 API 和 Q0 严格匹配到没有状态差异。

背景处理：
不能直接比较 Q/sum(Q)。湿润事件的背景流量往往更高，可能制造虚假的形状差异。
至少比较两种背景估计：事件前流量固定背景；训练期退水关系外推背景。
背景调整量仍是估计的事件响应，不是实测直接径流。负增量、截零和低增量事件都要记录；弱响应不要强行归一化。响应量与降雨量之比超过 1 也不能不加分析地自动截断或删除。

十五、第四步  控制混杂后检验量与形状

不要直接比较冬季干燥小雨和夏季湿润暴雨。

研究湿润影响时，控制总雨量、降雨天数、逐日雨型、季节和空间配置。研究空间影响时，也要共同考虑前期状态。

先画三张图：
图 1 响应量与事件前 API 的关系；
图 2 可比事件的干湿组归一化响应及不确定性；
图 3 响应重心滞后与 API 的条件关系。

形状主指标可预先确定为：
tau = 背景调整响应的时间重心 - 降雨时间重心，单位为天。

低复杂度统计对照：
S0：tau 由总雨量、降雨天数、日际雨型、季节解释；
S1：S0 加入 API；
S2：S1 加入降雨空间位置，必要时再加 API×空间交互。

先用少量预先选定变量，避免高自由度模型；只在可比数据范围内估计差异，不把无样本覆盖的状态组合强行外推。跨流域时先估计各流域关系，再考虑流域差异和总体结论。

空间位置代理：
D_event = sum[a_i × P_i,event × d_i] / sum[a_i × P_i,event]。
a_i 为雨站代表分区面积权重；P_i,event 为事件雨量；d_i 为代表分区至出口的代表性流路距离。

先检查 D_event 是否有足够变异、是否与总雨量和季节高度相关、是否被一个站控制。做留一雨站或替代空间权重敏感性分析。7—8 个站并不自动保证各区贡献可识别。

统计上先称为条件关联，不称为实际搬移降雨的因果试验。

十六、第五步  预先确定结果判定标准

响应量变大，而多个形状指标差异很小且估计精确：支持特定条件下主要调幅的近似。
控制因素后形状差异稳定，且对背景处理、年份与雨站方案稳健：支持继续研究状态相关响应形状。
更换背景、删除一个雨站或换年份后方向反转：证据不稳，先检查资料和分析方法。
未显著且区间很宽：证据不足，不等于证明形状相同。
仅重心不变：不能证明整个响应核形状都不变，可预先另定一个尾部或分布指标。
日尺度未发现时间差异：不能排除小时尺度差异。

预先确定有实际意义的差异容差，并报告差异大小、区间和逐年结果，不只报告 p 值。容差应根据用途与数据能力论证，不把任何示例值当通用标准。

不确定性可按完整水文年成组重采样，每次保留该年全部事件并重新拟合。不能把一次事件内的每日值作为独立重复。最终四年测试较短，应同时给出逐年效果；增加 bootstrap 次数不能增加独立年份。

十七、第六步  再验证模型结构价值

模型 A：前期状态允许调节响应幅度，响应核形状固定。
模型 B：前期状态允许调幅，额外允许核形状改变。

两者获得相同雨量、API 和其他背景信息，避免额外信息冒充结构收益。

若要更明确把收益归因于核形状，可先采用共同、冻结的产流及背景模块。若整个模型分别自由训练，应只声明整体结构的预测价值，不能把所有收益唯一归因于汇流核。

保持数据、预处理、训练预算和调参机会可比，重复随机种子，报告参数量。检查整体流量、响应量、重心、尾部和分年分状态误差。

仅总 NSE 上升，目标形状指标未改善，不足以支持“形状表达更正确”。

核随状态变化时，可按每份输入发生时的前期状态分配其延迟响应，然后累加到未来输出；避免按输出日状态重加权全部历史而造成含义混乱。

十八、遥感和其他流域怎样加入

长时期日雨量—日流量作为主实验，遥感重叠期可作辅助检验。核实遥感覆盖、云与质量标记、像元与流域尺度、直接反演与模型同化产品的区别。不用 2024 年地表状态默认代表 2006 年。

先检验 API 是否与可用遥感湿润状态具有一致变化，再判断遥感是否提供 API 之外的信息。模型输出与一种遥感产品一致，不等于内部机制已被完全证实。

扩大到其他流域时，保留共同主问题，但按降雨、融雪等主导过程分组。鹰落峡等寒区需考虑温度、雪和冰川影响。嵌套流域共享上游区域时，不应当作完全独立重复。

十九、可用的连续响应复核工具和查新提醒

ERRA 适用于连续长序列的集合响应估计，可联合分析降雨、前期状态与空间差异，提供代码和不确定性分析。不要给每场事件各拟合一个 ERRA 核。

事件分析用于直观认识与敏感性检验；雨季响应大量重叠时，可采用 ERRA 作连续时序复核。

泛泛的前期湿润影响、空间降雨影响、以及大坡岭加入土壤湿度资料均已有研究先例。具体贡献需收紧到调幅与变形的可区分性、日尺度可识别性、独立验证和结构必要性等问题。
